# SceneUniformBuffer Architecture

## Overview

`FSceneUniformBuffer` is UE's **scene-level Uniform Buffer aggregator** — it dynamically merges parameters from independent rendering subsystems (GPUScene, Nanite, HairStrands, VSM, Skinning, SplineMesh, ViewData, etc.) into a single `FSceneUniformParameters` cbuffer, accessible in all scene passes via `Scene.<MemberName>.<Field>`.

Key files:
- `Engine/Source/Runtime/Renderer/Public/SceneUniformBuffer.h` — FSceneUniformBuffer, FSceneUniformParameters, FSceneUniformBufferTypeRegistry, macros
- `Engine/Source/Runtime/Renderer/Private/SceneUniformBuffer.cpp` — BuildStructMetadata, Set/Get/GetBuffer, dirty tracking
- `Engine/Shaders/Private/SceneData.ush` — HLSL access functions (GetSceneData, LoadPrimitivePrimitiveSceneDataElement, etc.)
- `Engine/Source/Runtime/Renderer/Private/GPUScene.h` — FGPUSceneResourceParameters (example subsystem struct)

## Three-Layer Architecture

### Layer 1: Type Registry (Self-Registration)

Each subsystem independently declares itself as a SceneUB member without modifying any shared header:

```cpp
// GPUScene.h — declare
BEGIN_SHADER_PARAMETER_STRUCT(FGPUSceneResourceParameters, RENDERER_API)
    SHADER_PARAMETER_RDG_BUFFER_SRV(StructuredBuffer<float4>, GPUSceneInstanceSceneData)
    // ...
END_SHADER_PARAMETER_STRUCT()
DECLARE_SCENE_UB_STRUCT(FGPUSceneResourceParameters, GPUScene, RENDERER_API)

// GPUScene.cpp — implement (global constructor registers into list)
IMPLEMENT_SCENE_UB_STRUCT(FGPUSceneResourceParameters, GPUScene, ConstructDefaults)
```

Registration flow:
1. **Static init** (before main): global `TSceneUniformBufferMemberRegistration<T>` constructs → `Register()` adds to global list
2. **First access**: `FSceneUniformParameters::FTypeInfo::GetStructMetadata()` → `BuildStructMetadata()` → `CommitAll()` → each member calls `RegisterMember()` → `FShaderParametersMetadataBuilder.AddNestedStruct()` sorted by name → generates `FShaderParametersMetadata`
3. **Constraint**: `Metadata->GetSize() <= FSceneUniformParameters::MaxSize (4096)`

### Layer 2: FSceneUniformParameters (Fixed 4096-byte buffer)

```cpp
static constexpr size_t MaxSize = 4096;
uint8_t Data[MaxSize];  // raw bytes, layout described by FShaderParametersMetadata
```

Not a template — the true struct layout is runtime-generated by the metadata builder. This decouples struct size from compile-time member count.

### Layer 3: FSceneUniformBuffer (Dirty Tracking + Lazy RDG Buffer)

```cpp
class FSceneUniformBuffer {
    TRDGUniformBufferRef<FSceneUniformParameters> Buffer;
    bool bAnyMemberDirty;
    TBitArray<> MemberHasBeenSet;       // per-member bit
    TArray<uint8> CachedData;            // CPU-side cache of all members
};
```

- `Set(Registration, Value)` — Memcpy to CachedData at member offset; only marks dirty if `Memcmp` shows actual change
- `Get(Registration)` — returns ptr into CachedData; crashes if not set
- `GetOrDefault(Registration, GraphBuilder)` — lazy default construction via `DefaultValueFactory`
- `GetBuffer(GraphBuilder)` — **lazy create**: if dirty or null, fills defaults for unset members, Memcpy entire CachedData into RDG-allocated struct, creates `TRDGUniformBufferRef`. After creation, all passes share the same GPU buffer until something changes.

## Parameter Update Flow (Per Frame)

```
FDeferredShadingRenderer::Render()
  ① GPUScene.FillSceneUniformBuffer(GraphBuilder, GetSceneUniforms())
     → SceneUB.Set(SceneUB::GPUScene, params)

  ② GetSceneExtensionsRenderers().UpdateSceneUniformBuffer(GraphBuilder, GetSceneUniforms())
     → Iterates all ISceneExtensionRenderer::UpdateSceneUniformBuffer():
       - NaniteMaterials::  SceneUB.Set(SceneUB::NaniteMaterials, ...)
       - HairStrands::      SceneUB.Set(SceneUB::RenderCurve, ...)
       - VSMCache:          SceneUB.Set(SceneUB::VSMCache, ...)
       - SplineMesh:        SceneUB.Set(SceneUB::SplineMesh, ...)
       - Skinning:          SceneUB.Set(SceneUB::Skinning, ...)
       - ViewData:          SceneUB.Set(SceneUB::ViewData, ...)

  ③ Each Render Pass binds:
     BEGIN_SHADER_PARAMETER_STRUCT(FXxxPassParameters, )
         SHADER_PARAMETER_RDG_UNIFORM_BUFFER(FSceneUniformParameters, Scene)
     END_SHADER_PARAMETER_STRUCT()
     
     PassParameters->Scene = GetSceneUniforms().GetBuffer(GraphBuilder);
     // First call triggers buffer creation; subsequent calls reuse (not dirty)

  ④ RDG Execute: all passes share one GPU Constant Buffer → one upload per frame
```

## C++ → HLSL Mapping Chain

```
C++: BEGIN_SHADER_PARAMETER_STRUCT(FGPUSceneResourceParameters)
  → FShaderParametersMetadata (reflection)
  → FShaderParametersMetadataBuilder.AddNestedStruct("GPUScene", ...)
  → IMPLEMENT_STATIC_UNIFORM_BUFFER_SLOT(Scene) → shader binding slot
  → Auto-generated HLSL: cbuffer FSceneUniformParameters { struct {...} GPUScene; ... }

HLSL (SceneData.ush):
  Scene.GPUScene.GPUScenePrimitiveSceneData[index]
  Scene.GPUScene.GPUSceneInstanceSceneData[index]
  Scene.NaniteMaterials.MaterialData[...]
  Scene.ViewData.Common.InViews[...]
```

The mapping is **entirely name-based**: C++ macro field name → metadata → generated HLSL struct member → shader access.

SceneData.ush abstracts platform differences:
- Standard RDG path: `Scene.GPUScene.xxx`
- Global path (USE_GLOBAL_GPU_SCENE_DATA): `GPUScenePrimitiveSceneData[index]` directly
- RW path (USE_GPU_SCENE_DATA_RW): `GPUSceneWriter.GPUScenePrimitiveSceneDataRW[index]`

## Design Rationale

| Decision | Problem Solved |
|----------|---------------|
| Self-registration + deferred composition | Eliminates header coupling between subsystems; plugins can add members |
| Sort members by name | Deterministic layout across compilation units and platforms |
| 4096-byte fixed buffer + runtime metadata | Struct size not hardcoded at compile time |
| Dirty flag + Memcmp | Avoids unnecessary GPU buffer rebuilds when nothing changed |
| DefaultValueFactory | Lazy construction of default SRVs/textures; unused members don't allocate GPU resources |
| Single GetBuffer() → shared RDG UB | One GPU upload per frame, all passes read the same cbuffer |
| TBitArray MemberHasBeenSet | Distinguishes "never set" from "set to zero" |
